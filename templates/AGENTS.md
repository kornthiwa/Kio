## กติกาที่ agent ต้องทำตาม

- แก้เฉพาะส่วนที่เกี่ยวกับงาน อย่ารีแฟกเตอร์กว้างโดยไม่ถูกขอ
- อย่า commit / push / deploy จนกว่าจะถูกขอชัดเจน
- ก่อนเดา ให้เปิดไฟล์จริงใน repo ก่อน
- ถ้าไม่ชัวร์เรื่องพฤติกรรมระบบ ให้ถามคำถามสั้น ๆ หนึ่งข้อ

## สิ่งที่ห้าม

- commit ไฟล์ลับ (`.env`, credentials, keys)
- เปลี่ยน public API / schema โดยไม่บอกผลกระทบ
- เพิ่ม dependency ใหม่ถ้ามีทางใช้ของที่มีอยู่แล้ว
